Overview

This repository contains static web pages and a simple Lua obfuscator demo script. It's prepared for deployment on Render as a static site.

Get started

  1. Deploy this repo as a static site on Render (publish path: .).
  2. Use the Lua obfuscator script in the lua/ folder as a starting point for advanced obfuscation.

Files

  • lua/obfuscator.lua — simple, standalone Lua obfuscator (demonstration).
  • Lua Obfuscator docs — guidance and advanced techniques for Luau/Lua obfuscation and recommended options when adapting to Luau.
