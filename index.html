For technical users

There is a small bash wrapper at bin/obfuscate.sh you can use in CI or locally. The obfuscator sources are intentionally not linked from the public site to reduce casual downloads. To obtain the CLI or the server implementation, follow the instructions in the README (private access or deployment).
