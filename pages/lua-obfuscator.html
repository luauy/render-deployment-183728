Usage

The publicly visible site provides documentation and a client demo. The obfuscator CLI and server implementation are not directly downloadable from this site to avoid casual copying. You can:

  1. Use the browser demo (client-side) to try obfuscation locally (code never leaves your browser).
  2. Deploy the server in a private environment (see server/ for the server skeleton) and use the Obfuscate (Server) UI with a bearer token.
  3. Request access to the CLI/server sources via the repository owner if you need direct access.

CLI quick reference (local usage):

lua lua/obfuscator.lua --input in.lua --output out.lua --mode=lua --mangle-local --encrypt-strings --encode-numbers

Note: The CLI file may not be linked from the site. See README for access instructions.
