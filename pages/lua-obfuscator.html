Usage

lua lua/obfuscator.lua --input in.lua --output out.lua --mode=lua --mangle-local --encrypt-strings --encode-numbers

Flags:

  • --mode=lua|luau — choose the target language (default: lua). Use luau for more conservative transforms.
  • --mangle-local — mangle local variable names.
  • --encrypt-strings — replace string literals with a small runtime decoder.
  • --encode-numbers — split numeric literals into expressions.

Examples

Obfuscate a file (Luau-safe mode):

lua lua/obfuscator.lua --input lua/examples/sample.lua --output sample.obf.lua --mode=luau --mangle-local
