Usage

The repo includes both a browser demo (client-side) and a server API for hosted obfuscation. The hosted API is intended to run in a private deployment where the obfuscator implementation is not exposed to the public. 

lua lua/obfuscator.lua --input in.lua --output out.lua --mode=lua --mangle-local --encrypt-strings --encode-numbers

To use the server API, open the Obfuscate (Server) page and provide a valid bearer token. The server endpoints and deployment details are in server/.

To keep your obfuscator private, host the server/ folder in a private repository or private deployment and do not expose the sources publicly. You can compile the obfuscation core to WASM and only deploy the WASM binary to the server for additional protection (see server/wasm/README.md).
