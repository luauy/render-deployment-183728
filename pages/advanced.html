Luau-specific considerations

  • Luau supports optional type annotations (e.g., local x: number). The obfuscator has a --mode=luau which tries to avoid mangling annotated tokens.
  • Roblox environments restrict some runtime features such as loadstring. Runtime decoders may not work on all platforms; test your target environment.
